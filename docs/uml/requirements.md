# OneTrip – A Smart Travel Companion

## 1. Project Overview

OneTrip is a smart travel companion mobile application designed to help
users plan, manage, track, and summarize their trips from a single platform.

The application combines travel information extraction, AI-based itinerary
generation, budget-aware recommendations, expense tracking, maps, and
community-shared itineraries.

## 2. Problem Statement

Travel planning often requires users to use multiple applications for
tickets, itinerary planning, places, restaurants, accommodation, maps,
expenses, and trip management.

OneTrip aims to provide these functionalities through a single mobile
application with AI-assisted travel planning and budget management.

## 3. Target Users

- Individual travelers
- Students
- Budget travelers
- Families
- Groups of friends
- Users who want AI-assisted trip planning
